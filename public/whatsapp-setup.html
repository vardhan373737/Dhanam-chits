WhatsApp Setup Checklist

Use this page to set up Meta WhatsApp Cloud API, Twilio WhatsApp, or fallback mode for lender reminders.

Open Lender Center Open Payment Reminder

Meta WhatsApp Cloud API

Step 1
Open Meta Developers, select your app, then open the WhatsApp product.
Step 2
Copy WHATSAPP_META_PHONE_NUMBER_ID and WHATSAPP_META_ACCESS_TOKEN from WhatsApp API Setup.
Step 3
WHATSAPP_PROVIDER=meta WHATSAPP_PROVIDER_ORDER=meta

Twilio WhatsApp

Step 1
Open the Twilio Console, then find your Account Info and Messaging / WhatsApp sender setup.
Step 2
Copy TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, and TWILIO_WHATSAPP_FROM.
Step 3
WHATSAPP_PROVIDER=twilio WHATSAPP_PROVIDER_ORDER=twilio

Fallback Mode

  • Set both Meta and Twilio credentials.
  • Use WHATSAPP_PROVIDER=auto.
  • Use WHATSAPP_PROVIDER_ORDER=meta,twilio.
  • The app tries Meta first, then Twilio if Meta is unavailable.
Keep the secret values in your deployment dashboard or environment file. Do not commit them to the repository.
